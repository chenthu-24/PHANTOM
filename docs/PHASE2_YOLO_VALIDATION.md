# PHANTOM Phase 2 YOLO Local Validation

This phase keeps the phase 1 packages and adds the local YOLO-to-velocity pipeline:

`/perception/image_raw -> detector_node -> tracker_predictor_node -> tactical_fusion_node -> mode_manager_node -> subgoal_generator_node -> planner_controller_node -> safety_shield_node -> /cmd_vel`

The fake image and fake LaserScan generated by `sensor_bridge_node` are `PHASE2_FAKE_TEST_ONLY` local ROS graph inputs. They are not real platform data. The detector currently uses `PHASE2_YOLO_COCO_TEST_ONLY` COCO classes to prove that the local YOLOv8n model and ROS image pipeline are wired correctly; replace class selection after training `yellow_car` and `exit`.

## Install Runtime Dependencies

```bash
cd ~/phantom_ws
python3 -m pip install --upgrade pip
python3 -m pip install ultralytics opencv-python
```

## Download YOLOv8n

```bash
mkdir -p ~/phantom_ws/models/yolo
wget -O ~/phantom_ws/models/yolo/yolov8n.pt \
  https://github.com/ultralytics/assets/releases/download/v8.3.0/yolov8n.pt
ls -lh ~/phantom_ws/models/yolo/yolov8n.pt
```

This repository snapshot already includes `models/yolo/yolov8n.pt` for local testing.

## Train PHANTOM YOLOv8 Detector

The training script validates YOLO label files before it starts Ultralytics.
It expects class IDs in this order:

```text
0: exit
1: traffic_cone
2: yellow_car
```

Training command:

```bash
cd ~/phantom_ws
python scripts/train_yolov8_phantom.py --epochs 80
```

The generated dataset config is `config/phantom_yolo_data.yaml`. Training output
goes to `runs/yolo/phantom_yolov8_exit_cone_yellowcar`, and eval visualizations
go to `runs/yolo/predict_eval`.

Equivalent eval prediction command after training:

```bash
yolo detect predict \
  model=runs/yolo/phantom_yolov8_exit_cone_yellowcar/weights/best.pt \
  source=data/eval \
  imgsz=640 \
  project=runs/yolo \
  name=predict_eval \
  exist_ok=True
```

```bash

  model=~/phantom_ws/models/yolo/yolov8n.pt \
  source=0 \
  imgsz=416 \
  conf=0.4 \
```

Equivalent ROS node test mode:

```bash

cd ~/phantom_ws
colcon build --symlink-install

  -p mode:=test \
  -p model_path:=$HOME/phantom_ws/models/yolo/yolov8n.pt \
  -p test_source:=0 \
  -p imgsz:=416 \
```

## Run Full Phase 2 Pipeline

With fake image and fake scan:

```bash
source /opt/ros/foxy/setup.bash
cd ~/phantom_ws
source install/setup.bash
ros2 launch phantom_bringup phase2_yolo_test.launch.py \
  model_path:=$HOME/phantom_ws/models/yolo/yolov8n.pt \
  detector_mode:=ros \
  use_fake_image:=true
```

When a real camera node is already publishing `/perception/image_raw`, disable the fake image:

```bash
ros2 launch phantom_bringup phase2_yolo_test.launch.py \
  model_path:=$HOME/phantom_ws/models/yolo/yolov8n.pt \
  detector_mode:=ros \
  use_fake_image:=false
```

## Node Interfaces

`detector_node`

- Subscribes: `/perception/image_raw` (`sensor_msgs/msg/Image`)
- Publishes: `/det/yellow_boxes`, `/det/exit_boxes` (`std_msgs/msg/String`)

`tracker_predictor_node`

- Subscribes: `/det/yellow_boxes`
- Publishes: `/track/yellow_state`

`tactical_fusion_node`

- Subscribes: `/track/yellow_state`, `/det/exit_boxes`, `/nav/local_obstacle_features`
- Publishes: `/tactics/features`

`mode_manager_node`

- Subscribes: `/tactics/features`
- Publishes: `/tactics/mode`

`subgoal_generator_node`

- Subscribes: `/tactics/features`, `/tactics/mode`
- Publishes: `/tactics/subgoal_pose`

`planner_controller_node`

- Subscribes: `/nav/local_obstacle_features`, `/tactics/subgoal_pose`
- Publishes: `/cmd_vel_raw`

`safety_shield_node`

- Subscribes: `/cmd_vel_raw`, `/nav/local_obstacle_features`
- Publishes: `/cmd_vel`
